## 一、符号约定（已确认）

| 电机 | 角色 | 正角度（+）行为 | 验证命令 | 结论 |
|---|---|---|---|---|
| **M0** | 偏航 Yaw | **顺时针**（从电机正上方俯视） | `0p28` | ✅ 正角度 → 向右 |
| **M1** | 俯仰 Pitch | **向上**（抬头） | `1p28` | ✅ 正角度 → 抬头 |

> ⚠️ yaw 的"顺时针"是**俯视**看到的。若实际观察角度不同，符号要反过来。

### 关键推论

yaw 符号与标准右手系相反，指向逆解要带负号：

```
yaw   = -atan2(x, y)          ← 负号来自实测
pitch =  atan2(z, sqrt(x²+y²))
```

pitch 正 = 抬头，符合直觉，不变号。符号统一在逆解层处理，不写进固件，方便回退。

## 二、零点（2026-11-12 起改为 NVS 持久化）

**旧行为（已废弃）**：`FOC_Encoder::init()` 把"上电那一刻的位置"当 0°。
换一个上电姿态，`p0` 对应的物理位置就变一次，命令不可复现。

**现行为**：零点存在 NVS（key `pos_zero`），上电读取固定值。`h` 命令标定。

## 三、软限位（默认已改为 [0, 180°]）

固件默认 **[0, 180°]**（不再是 ±180° 对称）。`l` 单参数语义 = `[0, x]`。

| 轴 | 当前设置 | 实测安全范围 | 依据 |
|---|---|---|---|
| M0 yaw | [0, 180°] | ______ ~ ______ ° | 电源线长度 / 结构 |
| M1 pitch | [0, 180°] | ______ ~ ______ ° | 笔尾扫到 A 电机（笔套筒伸出 B 轴 43mm） |

命令：

```
l             查看当前范围 + 当前角度
l175          → [0, 175°]
l-5,175       非对称区间
1l60          → 电机1 [0, 60°]
h             把当前位置定为 0° 并写 NVS（限位同时重置 [0,180]）
```

超限会打（500ms 限流）：

```
[LIMIT] m0 target 190.0 deg clamped to 180.0 deg (range 0.0 ~ 180.0)
```

> **注意**：标定过零点（`h`）之后，限位是**绝对**的，不再随上电位置平移。
> 这正是可复现的前提。若还没标零，限位仍相对上电位置。

## 五、测量流程（照着做，约 20 分钟）

### 第 1 步 · 零点（每轴一次）

```
1. 断电，手把云台摆到机械 0°：
   M0 = 笔尖指向正前方（y 轴正向）
   M1 = 笔管水平（不抬头不低头）
2. 上电，等对齐完成（会吸一下，然后锁住）
3. 0?        确认 now 接近 0（若之前标过，可能不是 0，正常）
4. 0h        M0 零点写入 NVS
5. 1?        看 M1
6. 1h        M1 零点写入 NVS
7. 断电重启
8. 0?  1?    确认两个 now 都 ≈ 0.0  → 零点保持住了
```

### 第 2 步 · 找真实行程

```
1. 0p180     观察：顺利到位？顶住？有异响？
2. 0?        看 now 和 err
   - now ≈ 180、err ≈ 0  → 行程够，限位可保持 [0,180]
   - now 停在 17x、err 明显为正 → 行程不足，记下实际值
3. 0p0      转回来，确认回程没问题
4. 按实测值收紧：l175 / l170 ...
5. M1 同样，但注意笔尾会不会扫到 A 电机（这个要目视，别让它撞）
```

> 建议先在低速下试：`j` 把力矩上限临时调到 0.3A（`0j0.3`），撞到也不至于伤结构。
> 测完记得调回 `0j0.5`。

### 第 3 步 · 重复精度

```
循环 10 次：
  0p0   → 等停 → 0? → 记 now
  0p90  → 等停 → 0? → 记 now
M1 同样
```

> 要点：每次**等它完全停住**再看（`?` 里 vel 接近 0），别刚发命令就读。

### 第 4 步 · 指向验证

```
g0,1,0     正前方
g1,0,0     右侧 90°
g0,1,1     前方抬高 45°
g-1,0,0    左侧 90°
```

每个观察笔尖实际指向，与期望对比。
