# 云台串口命令速查表

固件版本：**FW-BUILD 2026-11-12-F**
串口：115200 8N1，**必须勾选"发送新行"**

## 通用规则

- **电机号写在命令最前面**：`0p90` = 电机0 去 90°，`1p90` = 电机1。
  **不写前缀 = 电机0**，所以 `p90` 等价 `0p90`。
- 位置相关命令（`p` / `q` / `l`）单位统一是 **度**。
- 速度相关（`v` / `q` 的速度字段 / `j` 的电流）是 **rad/s** 和 **A**。
- 标定类命令（`h` / `l` / `z`）会写进 NVS，断电不丢。

---

## 一、日常使用（99% 的情况只用这三条）

| 命令 | 例子 | 作用 |
|---|---|---|
| `p<度>` | `0p0` `0p180` `1p90` | 位置模式，平滑转到指定角度 |
| `q<队列>` | `q0,0,30;0,180,30` | 轨迹队列，按顺序跑一条路径 |
| `g<方向>` | `g0,1,0` `g0.5,1,0.3` | 指向命令，给空间方向自动算两轴角度 |

### `p` —— 最常用

```
0p0        电机0 回 0°
0p180      电机0 去 180°
1p90       电机1 去 90°
```
内部自动走 7 段 S 曲线，不用自己写加减速。

### `q` —— 一条路径连跑

格式：`电机号,目标度,速度;电机号,目标度,速度;...`（分号隔开每一段）

```
q0,0,30;0,180,30;0,0,30                 电机0 从当前位置 →0°→180°→0°
q0,0,20;1,90,20;0,180,20;1,0,20         两轴交替摆动
```

- 速度 30 = 30 rad/s（约 5 圈/秒，一般 10~30 够用）
- 上限 64 段，发一次从头跑到尾，串口会打 `#n/总数`，跑完打 `[QUEUE] done`
- 优点：段与段之间不减速，连续平滑；`p` 每次都是独立一次运动

### `g` —— 给方向，不给角度

```
g0,1,0       正前方
g1,0,0       正右方
g0,1,1       正前方抬高 45°
g0.5,1,0.3   斜前右方，速度 0.3（rad/s，省略则用默认）
```
内部做逆解：`yaw = atan2(x,y)`、`pitch = atan2(z, √(x²+y²))`，
两轴共用一条 S 曲线同时到位（不会一个先到一个后到）。

## 二、装配标定（装好之后做一次，以后不用管）

| 命令 | 作用 |
|---|---|
| `h` | **把当前位置定为该轴 0°**，写 NVS，限位同时重置为 [0,180°] |
| `l` | 查限位；`l170` = [0,170°]；`l-10,170` = 非对称 |
| `z yaw,pitch` | 指向命令的零位偏置（`z` 单独发＝查看） |
| `y` | 翻转 yaw 方向（`y1` / `y-1` 直接指定） |

### 标定流程

```
1. 断电，手把云台摆到机械 0° 位置
2. 上电，等对齐完成（会吸一下）
3. 0?          确认 now ≈ 0.0deg
4. 0h          M0 零点存好（限位自动变 [0,180]）
5. 1h          M1 同理
6. 断电重启，0? 确认零点还在
7. 0p180       验证是不是转到机械 180°
```

## 三、查看与救急

| 命令 | 作用 |
|---|---|
| `?` | 两轴状态：模式、目标、当前位置、误差、速度、电流、故障码 |
| `0?` | 只看电机0 |
| `r` | 清故障（故障时发运动命令也会自动清） |
| `d` | 诊断模式开关：关遥测，只留诊断行，抓偶发 bug |
| `m` | 单次测量打印 |
| `e` | 急停：清空该电机队列并停住 |

`?` 输出示例：
```
[STAT] m0 mode=POSITION fault=0x00 target=90.0 now=89.8 err=+0.2
       vel=0.01 iq=0.03/0.50 kp=0.20 kd=0.30 vkp=0.150 limit=[0.0,180.0]deg
```

## 四、内环调试（正常使用完全不用碰）

这一栏是**调参/排障**时才用的。云台跑位置命令时，速度环和电流环是固件在内部自动跑的，不需要你发指令。

| 命令 | 作用 |
|---|---|
| `i0.3` | 电流模式，直接给 iq（A）。只用来测硬件、验证三相接线 |
| `v10` | 速度模式，单位 rad/s。用来单独验证速度环 |
| `w` / `w0.25` | 速度环 P。**这个是"摆不摆"的真正旋钮** |
| `k` / `k0.1,0.3` | 位置环 P 和 Kd。P 默认 0.2 已够用，Kd 只是死区里的微刹车 |
| `j` / `j1.2` | 速度环输出限幅 = 力矩上限（A），默认 0.5 |
| `c` | 电角度重标定（换电机/改接线后要做） |
| `s` / `x` | 查 NVS 存档 / 清 NVS 存档 |
| `a` | 切换"每次上电都对齐"/"有存档就跳过" |

### 关于 `k` 和 `j` 还要不要用

- **`j`（力矩上限）**：默认 0.5A 已经在装配好的云台上验证过够用。只有加负载、
  明显"没力气"时才往上加，且要边加边看发热。
- **`k`（位置环 P / Kd）**：默认 P=0.2、Kd=0.3 是实测收敛的。之前"Kd 调到 1.0
  完全没效果"那一轮已经证明：**治摆动该调的是 `w`，不是 `k`**。所以 `k` 留着备用，
  日常不用发。
- **`w`（速度环 P）**：默认 m0=0.15 / m1=0.05，是分开给的。
  只有换电机、加负载、机械结构变了才需要重调。

## 五、当前生效的参数

| 参数 | 值 | 说明 |
|---|---|---|
| 位置环 P | 0.20 | 单位「度」，等效约 11.5 rad/s per rad |
| 位置环 Kd | 0.30 | 速度阻尼，主要在死区内起刹车作用 |
| 位置死区 | 0.2° | 小于此误差不再修正，避免到点抖动 |
| 速度环 P | m0=0.15 / m1=0.05 | 决定阻尼比，按轴分开给 |
| 速度环 I | 1.0 | |
| 速度反馈滤波 Tf | 0.025 s | 压电流纹波噪声 |
| 力矩上限 | 0.5 A | 速度环输出限幅 |
| 轨迹 jerk | 120 rad/s³ | S 曲线加加速度上限，越小越柔 |
| 轨迹加速度 | 30 rad/s² | |
| 软限位 | [0, 180°] | `h` 标定后 |
