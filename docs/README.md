# FOC 双轴云台 · 面试话术版

> 两块板、一条 CAN 总线、两个电机，一条命令指到任意角度，能画圆、8 字、螺旋。
> 本页只留**能拿去面试说的东西**：十个重难点 + 必背数字 + 追问预备。
> 完整调试记录在文末索引里，需要翻细节再看。

---

## 1. 三十秒开场（背下来）

> "这是我自研的双轴指向云台。底层 FOC 是我手写的，没用 SimpleFOC；上层挂了 CANopen CiA 402 从站，F103 做主机发轨迹，ESP32 跑控制。验收不靠眼睛看，靠遥测数据算：圆的半径误差 0.2°、8 字频率比实测 2.00、双轴时序偏差 0.015°，都比编码器分辨率还小。"

**三个一定要说出去的数**：`0.2°`（圆半径误差）、`2.00`（8 字频率比）、`0.015°`（双轴同步）。

## 2. 系统长什么样

```
PC ──COM4──> STM32F103 主站（发指令、跑轨迹、20ms 周期）
                  │
            CAN 500kbps
                  │
        ESP32-S3 + MCP2515 从站（节点1=yaw 节点2=pitch）
                  │  I2C 400k + PWM
        AS5600 编码器 ×2 + 2208 云台电机 ×2
```

| 分工 | 谁 | 干什么 |
|---|---|---|
| **去哪** | F103 主站 | 指向逆解、轨迹生成、RPDO 下发 |
| **怎么动** | ESP32 从站 | CiA 402 状态机、三环、保护 |
| **看什么** | COM3 | 遥测日志、`?` 状态、诊断 |

## 4. 十个重难点（面试主体）

每个都按 **现象 → 根因 → 解法 → 结果** 写，最后一句是可以直接说出口的话。

### ① 静止时原地微震 ⭐ 最值得讲

- **现象**：电机停住后原地小幅抖动，偶尔突然抖一下，yaw 轴严重。
- **弯路**：以为是死区、积分饱和、编码器噪声，连加 **八个补丁**（死区补偿、iq 清零、软死区、到位锁定、冻结积分、自适应、uq 低通、误差低通）——**全部失败，有的更糟**。
- **根因**：`loop()` 里有个 `delay(1)`，控制频率只有 **270 Hz**，比参考实现低 18 倍。PID 积分增量 ∝ `I × Ts × 误差`，`Ts` 大 18 倍，同样参数每步积分量就放大 18 倍 → 积分过冲 → 输出抖。
- **解法**：删 `delay`、I2C 提到 400 kHz、遥测降频 → 控制频率回到 1 kHz。
- **结果**：八个补丁全删，回归纯三环，停住一动不动。
- **怎么说**：「我第一反应是加补偿，加了八个全失败。后来发现参数本身没错，是它跟采样率强耦合——采样周期差 18 倍，同样的 I 每步积分量就差 18 倍。所以我做的是删代码，不是加代码。」

### ② 竖直轴持续摆动：外环 Kd 怎么调都没用 ⭐ 最有技术含量

- **现象**：yaw 轴在 ±11° 等幅摆动，给位置环加 Kd 阻尼，`0.3→1.0` 完全没变化。
- **根因**：把 Kd 代进速度环，`iq = Pv·Kp·err − Pv·(1+Kd)·ω`——**阻尼系数只能从 `Pv` 抬到 `Pv·(1+Kd)`**。当时 `Pv=0.02`，Kd 从 0.3 加到 1.0，绝对值只动了 0.02，阻尼比几乎不变。**"没反应"是数学必然，不是命令没发进去。**
- **解法**：动内环——速度环 P `0.02 → 0.15`，并用 numpy 复刻三环做仿真验证（旧参数下 6° 扰动会越摆越大到 28°，新参数 0.52 s 收敛）。
- **结果**：不摆了。附带结论：**阻尼比由内环 P 决定，外环 Kd 调不动**；且惯量差 50 倍的两个轴最优 P 差几倍（yaw 0.15 / pitch 0.05）。
- **怎么说**：「串级系统的阻尼比由内环增益决定。我一开始在位置环加 Kd，从 0.3 加到 1.0 一点效果没有——因为代入速度环后，阻尼系数只从 0.02 抬到 0.04。真正起作用的是把速度环 P 从 0.02 提到 0.15。」

### ③ 连续三轮误判，根因是命令被拆断

- **现象**：发 `0k0.05`（调位置环 P）后电机变软、慢慢顺时针转；加大参数就报堵转。
- **根因**：串口把 `0k0.05` 拆成了两条——`0k`（查询）+ 残留数字 `0.05` 被当成**速度 0.05 rad/s**。也就是说前两轮"变软""力矩不足"的结论**全部建立在假象上**。
- **解法**：即时命令表只留不带参数的；超时 200 ms → 800 ms；**删掉"纯数字=速度"的兜底**；未知命令显式拒绝并回显。
- **结果**：误判链断掉，重新观察才看到真现象（等幅振荡，手扶能停）。
- **怎么说**：「最危险的不是报错，是把不认识的输入当成有效指令。它把我的调试动作变成了机器的运动命令，还一声不响，导致我连续三轮误判成力矩不足。」

### ④ 上电就自己震：软限位被代码偷偷放宽了

- **现象**：以前不震，改了一版之后一上电就原地狂震，iq 顶到 0.5 A 限幅。
- **根因**：上电时把目标位置 `constrain(当前角, 限位)` 夹进软限位。pitch 上电读数 −30°，限位 `[0,180]`，目标被夹到 0° → **误差恒为 30°，位置环一直往边界顶**，顶不动弹回来再顶。
- **解法**：不用"放宽限位"（那是定时炸弹，曾把限位永久扩成 `[-267°, 180°]` 导致保护失效），改成 `_nearFull(上电角)`——**折回同一物理位置的等价角，限位一个数都不动**。
- **结果**：上电静止，且换任意上电姿态都成立。
- **怎么说**：「根因是我自己写的'自动放宽保护阈值'。保护阈值只能人来改，代码永远不许自动放宽——要治读数越界，治的是坐标口径，不是阈值。」

### ⑤ 编码器"丢弃一帧"变成永久冻结

- **现象**：电机转到一半突然停住，3 秒后报位置超差。
- **根因**：防毛刺代码发现跳变就 `return`，但**没更新参考角**。下一拍 `Δ` 还是那个大值而 `Ts` 已经变小 → 速度反而更大 → 继续丢弃 → **参考点永远追不上，角度冻死**。
- **解法**：连续 2 拍超限仍丢弃，**连续 3 拍强制重同步**并打印 `[ENC] resync`。
- **怎么说**：「防御性代码也会死锁。只做'跳过本次'而不做'跳出异常状态'，就会永久卡住。原则是宁可角度跳一下，也绝不允许冻死。」

### ⑥ 电机有劲但推不动（CANopen 心跳）

- **现象**：CANopen 使能后电机是硬的、有电流，但完全不响应。
- **根因**：从站的心跳消费配错节点号（`mon_node`），一直判定"主站掉线"→ 主动降档并锁轴。这是**保护逻辑在正常工作**，不是驱动坏了。
- **解法**：把 RPDO/SDO 收包也算作"主站活着"；`mon_node==0` 时跳过检测。
- **怎么说**：「'有劲但不动'不是力矩问题，是保护逻辑在锁轴。判断方法是看电流——iq 有值说明电流环在闭环，没转矩说明不是功率问题。」

### ⑦ 底层故障清了，上层还是 Fault

- **现象**：发清故障指令，`?` 显示 `fault=0x00`，但电机依然不动、依然软。
- **根因**：有**两层故障**——底层过流/堵转保护，和 CANopen CiA 402 的 Fault 锁存态。底层清了不代表上层清了。
- **解法**：`0x6040` 先写 `0x0000` 再写 `0x0080`（**bit7 上升沿**）才能退出 Fault；一键使能命令里自动先做这一步。
- **怎么说**：「CiA 402 的 Fault 是锁存的，必须给一个 bit7 的上升沿才出来。我当时只清了底层标志，所以一直卡在 Fault。」

### ⑧ `a90 90` 发进去没反应（串口丢字节）

- **现象**：单字符命令都正常，多字符命令死活没反应。
- **根因**：F103 用**单字节轮询**收串口。115200 下每 87 µs 来一个字节，主循环稍慢就**静默丢字符**，还不报错。
- **解法**：改中断接收 + 64 字节环形缓冲，溢出自动重启。
- **怎么说**：「115200 下一个字节只有 87 微秒，轮询方式主循环稍微一慢就丢，而且不报错。改成中断 + 环形缓冲后一次就对。」

### ⑨ `Serial.printf` 会拖垮控制环（同一个根因，三种表现）

| 表现 | 怎么发现的 |
|---|---|
| 画圆时电机变软、不动 | 日志 18 KB/s，超过 115200 上限，主循环被打印阻塞 → 控制环掉频 → 判堵转 → 释放 |
| 两轴处理错开 11 ms | 一帧日志 5 ms，第二帧正好落在打印期间排队 |
| 测出的抖动大 50 倍 | 遥测每 loop 打一行，把 1 kHz 压到 130 Hz，**测出来的是打印自己** |

- **解法**：所有打印限速；流式下发时自动关闭软启动；常驻显示 `ctrl loop = xxx Hz`。
- **怎么说**：「嵌入式里最贵的不是运算，是打印。我三次踩坑都是同一个根因——串口阻塞主循环，所以我后来加了循环频率的常驻显示，一眼就能看出有没有被拖慢。」

### ⑩ CAN 位定时差 6%：帧发出去，对面零反应、无报错

- **现象**：CAN 帧能发，但对方一点反应没有，也没有任何错误帧。
- **根因**：CubeMX 默认 `BS2=1TQ`，算出 **529.4 kbps**，和对面 500 k 差 6%。误差超出容差，采样点全错。
- **解法**：`Prescaler=4, BS1=15TQ, BS2=2TQ` → 36 MHz/4/18 = 精确 500 k。
- **怎么说**：「波特率差 6% 是最阴的一类问题——不发错误、不报故障，就是对面听不懂。位定时要自己算，不能信默认值。」

## 5. 另外三条小结论（被追问时加分）

| 结论 | 数据 / 依据 |
|---|---|
| **电流采样 2 次平均** | 单次 iq 噪声 0.54 A，2 次平均降到 0.23 A，控制频率仍有 965 Hz；4 次平均降到 420 Hz 就出问题——**采样率和 PID 强耦合，这里又应了一次** |
| **双轴不需要 SYNC 帧** | 6 字节标准帧 95 位 @500k = 190 µs 物理下限；实测生效间隔 369 µs ≈ 0.015°，而编码器一格就 0.09°——**差一个数量级，不够格上 SYNC** |
| **S 曲线在流式下发时失效** | 主站 20 ms 一个目标，每来一次就重启轨迹，匀速段永远走不到。所以连续轨迹的平滑实际来自**主站小步长**，S 曲线只在单点定位时生效 |

## 6. 必背数字

| 项 | 值 | 备注 |
|---|---|---|
| 控制频率 | **≈1 kHz** | 电流环同频，位置环降频，主站 20 ms |
| 电流环 / 速度环 / 位置环 P | 5 / 0.15(yaw)·0.05(pitch) / 0.2 | 速度环限幅 0.5 A |
| iq 噪声 | **0.54 → 0.23 A** | 2 次采样平均 |
| 定位稳态误差 | **±0.5°** | 12 bit 编码器一格 0.088° |
| 圆 | 半径 **29.8°**（设定 30），最大偏差 **1.3°**，覆盖 360° | 128 点遥测 + 最小二乘拟合 |
| 8 字 | 俯仰/偏航频率比 **2.00**（理论 2） | 硬判据，椭圆也是 1:1 |
| 螺旋 | 半径 3.9 → 28.5 → 3.6°，3 圈 | 半径包络 |
| 双轴同步 | **369 µs ≈ 0.015°** | 小于编码器一格 6 倍 |
| 轨迹电流峰值 | **0.13 A**，占 0.5 A 限幅 26% | 说明远未到力矩极限 |
| 电压利用率 | **+15.5%** | SVPWM vs SPWM，即 2/√3 |

## 7. 追问预备（今天被问崩的，标准答案）

**Q：为什么不用 SimpleFOC？**
> 「两个原因。一是那类库是电压模式，没有真正的电流环，我要做力矩必须自己写 iq 闭环；二是我要把 CiA 402 集成进来，现成库的对象字典和我的保护逻辑会打架。学原理只是顺带收益。」

**Q：三环为什么电流环在最里？**
> 「电流环对应电气时间常数 L/R，毫秒级；速度环对应机械时间常数，几十到几百毫秒。相差一到两个数量级才能解耦——外层设计时可以把内层当成理想的力矩源。带宽一般差 5~10 倍，再大就互相干扰。」

**Q：电流怎么采？**
> 「采两相，第三相由 ia+ib+ic=0 算。采样点放在 PWM 中心对齐的计数顶点，那一刻开关动作最少，噪声最小。」

**Q：CiA 402 状态机怎么走？**
> 「Switch on disabled —0x06→ Ready to switch on —0x07→ Switched on —0x0F→ Operation enabled。状态字低四位分别是 0x40 / 0x21 / 0x23 / 0x27。」

**Q：Fault 怎么退出？**
> 「0x6040 先写 0x0000 再写 0x0080，给 bit7 一个上升沿，回到 Switch on disabled，再重新 06→07→0F。注意这是 CANopen 层的锁存，和底层过流保护是两套。」

**Q：500K 是什么意思？**
> 「是波特率，不是周期。周期是主站多久发一次帧，这里是 20 ms。」

**Q：怎么证明它是准的？**
> 「不看眼睛看数据。采 10 Hz 遥测，用最小二乘圆拟合算圆心和半径：设定 30°，实测 29.8°，最大偏差 1.3°，角度覆盖满 360°。8 字用频率比判形，实测 2.00。」

**Q：为什么不做力控？**
> 「我的负载是指向，刚性定位是正确选择，柔顺反而是负分。力控需要力矩传感器或精确的 Kt 标定，我没有，评估后认为投入产出不划算，把精力放在通信和轨迹上。」

## 8. 命令速查（只留常用的）

## 10. 现状

**已完成**：FOC 三环、SVPWM、双轴联动、CANopen 四块全通、三类轨迹、双轴同步实测、机械装配。

**已知边界**：软限位 0~180° 可配，实际行程受结构挡块限制；激光笔未装，指向的目视验证还没做。

**明确不做**：力控（场景不需要，无力矩传感器）。
