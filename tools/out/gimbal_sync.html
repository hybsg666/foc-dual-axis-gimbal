双轴同步验证 · 归一化进度曲线

每条曲线：横轴 = yaw 完成度，纵轴 = pitch 完成度。 若两轴严格同步，曲线应是一条 从 (0,0) 到 (100%,100%) 的直线；弯曲就代表一轴超前一轴落后。

① 正前方 → 右前方 45°

yaw -45.0° / pitch +0.0° · span 0.785 rad · T = 0.594s · 同步误差 0.000 ms

② 正前方 → 斜上 45°

yaw -0.0° / pitch +45.0° · span 0.785 rad · T = 0.594s · 同步误差 0.000 ms

③ 大角度复合 (yaw 63° + pitch 22°)

yaw -63.4° / pitch +11.4° · span 1.107 rad · T = 0.666s · 同步误差 0.000 ms

④ 已在右方，转到正前方（yaw 反向）

yaw +90.0° / pitch +0.0° · span 1.571 rad · T = 0.748s · 同步误差 0.000 ms

⑤ 一轴不动（纯 pitch）

yaw -0.0° / pitch +31.0° · span 0.540 rad · T = 0.524s · 同步误差 0.000 ms

⑥ 一轴不动（纯 yaw）

yaw -26.6° / pitch +0.0° · span 0.464 rad · T = 0.498s · 同步误差 0.000 ms

⑦ 接近反向 170°（大行程）

yaw -170.4° / pitch +0.0° · span 2.973 rad · T = 1.003s · 同步误差 0.000 ms

怎么读：曲线越接近对角直线 → 两轴越同步。所有案例的同步误差都在 5 ms 以内， 说明"快的降速到慢的节奏"这套反解是有效的。

注意：这里的"同步"指的是同起同停，路径是关节空间的直线 （yaw 和 pitch 按同一比例变化），不是笛卡尔空间的大圆直线。角度小时两者几乎重合； 大角度时会有可见偏差，要真直线需要每拍笛卡尔反解（在线插补）。
