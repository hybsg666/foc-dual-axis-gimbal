# 双轴 FOC 指向云台（自研 FOC + CANopen 从站）

一套从电机矢量控制到工业总线的完整实现：**未使用 SimpleFOC 等现成电机库**，FOC 驱动、三环闭环、CANopen CiA 301/402 从站、轨迹规划全部手写。

硬件为 ESP32-S3（从站）+ STM32F103（主站），驱动两台 DengFOC 2208 空心轴盘式电机，可让云台按指令指向、画圆、走 8 字与螺旋。

---

## 关键指标

| 项目 | 数值 |
|---|---|
| 调制方式 | SVPWM 零序注入（min-max），电压利用率 **+15.5%** |
| 电流噪声 | iq **0.54 → 0.23 A**（每通道 2 次过采样平均） |
| 定位稳态误差 | **±0.5°** |
| 控制循环 | 约 **1 kHz**，电流/速度/位置三环同频顺序执行 |
| PWM 载波 | 30 kHz（8 bit） |
| CAN | 500 kbps，MCP2515 外扩控制器 |
| 双轴生效间隔 | **369 µs**，折算角度偏差 **0.015°**（小于 12 bit 编码器一格 0.09°） |
| 圆轨迹 | 半径 **29.8°**（设定 30°），覆盖 **360°** |
| 8 字轨迹 | 横纵频率比 **2.00**（理论 2.00，形状硬判据） |
| 电流峰值 | **0.13 A**，占 0.5 A 限幅的 26% |

## 系统架构

```
  PC
   │  USB 串口（115200）
   ▼
┌──────────────────┐   CAN 500 kbps   ┌────────────────────┐
│  STM32F103 主站   │◄────────────────►│  ESP32-S3 从站      │
│  · 串口命令解析    │   0x201 / 0x202  │  · FOC 三环控制     │
│  · 轨迹生成        │   RPDO 周期下发   │  · CiA 301 / 402    │
│  · 20 ms 下发 RPDO │   0x181 / 0x182  │  · 对象字典 + 状态机 │
└──────────────────┘   TPDO 状态回传   └─────────┬──────────┘
                                                 │ 双路 I2C + 3 路 PWM
                                          ┌──────┴──────┐
                                          ▼             ▼
                                     M0 yaw 电机    M1 pitch 电机
                                     AS5600 编码器   AS5600 编码器
```

- **节点 1 = M0（yaw，竖直轴）**，**节点 2 = M1（pitch，水平轴）**
- RPDO `0x201/0x202`：控制字 2 B + 目标位置 4 B（单位 0.01°）
- TPDO `0x181/0x182`：状态字 2 B + 实际位置 4 B

| 功能 | M0（yaw） | M1（pitch） |
|---|---|---|
| PWM A / B / C | 15 / 16 / 17 | 18 / 8 / 9 |
| 使能 EN | 10 | 10（与 M0 共用） |
| I2C SDA / SCL | 11 / 12 | 13 / 14 |
| 电流采样 ADC | 4 / 5 | 6 / 7 |

## 快速开始

### 1. 烧录从站（ESP32-S3）

```bash
pio run -t upload --upload-port COM3
```

### 2. 烧录主站（STM32F103）

用 Keil MDK 打开 `STM32F103/MDK-ARM/STM32F103.uvprojx`，编译并下载；或用 STM32CubeProgrammer 烧录 `.hex`。

### 3. 上电自检

| 顺序 | 操作 | 预期 |
|---|---|---|
| 1 | 打开 COM3（115200） | 打印 `[CO] boot-up`，节点 1/2 上线 |
| 2 | 打开 COM4，发 `h` | 打印命令表 |
| 3 | 发 `b` | 两轴依次使能，电机变硬 |
| 4 | 发 `a90 90` | 两轴同时转到 90° |
| 5 | 发 `c` | 开始画圆，`0` 停止 |

> 串口工具必须勾选“发送新行”，否则命令不生效。

## 串口命令

### COM4 —— STM32F103 主站

| 命令 | 作用 |
|---|---|
| `h` | 打印命令表 |
| `b` | 双轴使能（内部自动先做故障复位） |
| `a<yaw> <pitch>` | 绝对定位，例 `a90 90` |
| `g<方位> <仰角>` | 指向，例 `g30 20`（方位 0 = 正前，正 = 右转） |
| `c` / `i` / `w` | 圆 / 8 字 / 螺旋轨迹 |
| `0` | 停止轨迹 |
| `f` | 复位 CiA 402 故障 |
| `e` | 单轴使能 |

### COM3 —— ESP32-S3 从站

| 命令 | 作用 |
|---|---|
| `?` | 两轴状态（角度、误差、速度、电流、故障、控制频率） |
| `p<度>` | 位置模式，例 `0p90` `1p180` |
| `q<队列>` | 轨迹队列，例 `q0,0,30;0,180,30` |
| `g x,y,z` | 空间向量指向 |
| `l` | 查询/设置软限位，例 `l170` `l-10,170` |
| `h` | 当前位置设为 0° |
| `r` / `f` | 清底层故障 / 复位 CiA 402 故障 |
| `t` | 板内 CANopen 回环自检（5 项） |
| `d` | 诊断模式（关闭遥测，避免打印阻塞控制环） |
| `oskew` | 统计双轴 RPDO 到达间隔 |

完整说明见 [`docs/串口命令速查.md`](docs/串口命令速查.md)。

## 实现要点

### SVPWM 零序注入

传统七段式 SVPWM 需要判断扇区、计算作用时间；本工程用 min-max 中点注入，与七段式在数学上完全等效（线电压一致），但只需两次比较加一次加法：

```c
float umax = max(Ua, max(Ub, Uc));
float umin = min(Ua, min(Ub, Uc));
float uoff = -(umax + umin) * 0.5f;   // 三相各加此值
```

基波幅值由 `Vbus/2` 提高到 `Vbus/√3`，比值 1.1547，即电压利用率 +15.47%。计算量小，是控制循环能压进 1 ms 的前提。

### 三环同频

电流、速度、位置三环在同一个控制循环内顺序执行，未做分频：

```
位置环 → 速度环 → 电流环 → PWM 输出
```

分频的前提是内环能比外环快一个数量级。本平台受采样通路限制（`analogRead` 为软件启动、AS5600 走 I2C 每次约 70 µs），电流环上限约 1 kHz，无法显著高于外环，因此分频只会把外环变慢。

稳定性依赖的是**闭环带宽**而非采样次数：电流环 `P=5 / I=200` 使时间常数落在亚毫秒级，位置环 `P=0.2` 为秒级，即使采样率相同，时间尺度仍分离两个数量级；且外环指令当拍即进入内环，不存在采样延迟。

### CANopen 从站（手写）

未引入 CANopenNode 等协议栈，只实现所需的 CiA 301 子集与 CiA 402：

| 模块 | 实现方式 |
|---|---|
| 对象字典 | `switch-case` 硬编码，按索引/子索引分发读写 |
| NMT | `0x000` 两字节（命令 + 节点号） |
| 心跳 | `0x700 + node`，定时生产，同时消费主站心跳 |
| SDO 服务端 | `0x600 / 0x580`，8 字节加速传送，支持中止码 |
| PDO | `0x201/0x202` 接收、`0x181/0x182` 发送，定长映射 |
| CiA 402 | `0x6040 / 0x6041` 四档状态机，`0x607A` 目标位置门禁，故障锁存 |

两个易错点：

- **Fault 是锁存态**，仅清底层保护标志不会退出，必须让 `0x6040` 的 bit7 产生上升沿（先写 `0x0000` 再写 `0x0080`）。
- **CAN 位定时**：`Prescaler=4, BS1=15TQ, BS2=2TQ`，36 MHz/4/18 = 500 kbps。CubeMX 默认 `BS2=1TQ` 会得到 529.4 kbps，现象是帧正常发出、对端零响应且无任何报错。

### 轨迹规划

- 7 段 S 曲线，jerk 限幅 120 rad/s³，按绝对时间查表而非逐拍累加，不受 `dt` 抖动影响
- 环形队列深度 64，支持批量入队连续执行
- 双轴共用同一条以“本段最大行程”为标尺的 S 曲线，保证**同起同停**；若各按自身行程规划，S 曲线形状随速度变化，中途仍会一前一后

### 保护

| 层 | 内容 |
|---|---|
| 底层 | 过流、堵转、位置超差、指令超时，位标志叠加 |
| 位置层 | 软限位（可运行时配置，存 NVS），上电目标钳制在限位内 |
| 协议层 | CiA 402 Fault 锁存，需 bit7 上升沿复位 |

零点与换相方向绑定存储：换相方向改变后旧零点自动作废，强制重新对齐，避免“拿错零位通电”。

## 已知限制

| 项 | 说明 |
|---|---|
| 电流环频率 | 约 1 kHz。受 Arduino `analogRead` 与 I2C 编码器限制；未使用 MCPWM + ADC DMA，若要提升需改底层并重调全部 PID |
| 编码器接口 | AS5600 为 I2C，单次读取约 70 µs，是电流环提高频率的主要瓶颈；换 SPI 磁编码器（如 MT6701）可降至 5 µs |
| 力控 | 未实现。无扭矩传感器，且指向场景需要刚性定位，评估后未做 |
| 心跳超时降档 | 未实现，`CMD_TIMEOUT` 为 100 s |
| SYNC 同步帧 | 未实现。实测双轴间隔 369 µs、折算 0.015°，小于编码器分辨率，不需要 |
| PDO 映射 | 固定映射，不支持运行时改写 |
